MASTER / Re:MASTER スコアからチュウニズム準拠OPを算出するブックマークレット

♪ maimai OVERPOWER

PC: ↑ ブックマークバーにドラッグ＆ドロップ

② ブラウザで適当なページをブックマークに追加
③ そのブックマークを編集してURLを全部消し、①でコピーしたURLを貼り付けて保存
④ maimaiNETを開いた状態でそのブックマークをタップ → 起動！

使い方

  1. maimaiNET にログインする
  2. ページを開いたまま、ブックマークバーのボタンをクリック
  3. クリック直後に起動確認トーストが右上に表示されます
  4. 自動でMASTER & Re:MASTERスコアと譜面定数を取得してOPを計算します

計算式

sc  =  達成率 × 10,000
範囲 計算式
AP+  (101.0000%) (定数+2)×5 + 1.5 + 5.75 = (定数+2)×5 + 7.25
SSS+以上  (sc≥1,005,000) (定数+2)×5 + 補正1 + (sc−1,005,000)×0.00115
S〜SSS  (sc<1,005,000) (定数+2)×(sc÷1,005,000)×5 + 補正1
補正1（コンボボーナス）： AP+  +1.5  ／  AP  +1.25  ／  FC+  +1.0  ／  FC  +0.5  ／  なし  +0
※ 譜面定数は otoge-db / lxns.net API から自動取得します
※ 日本独自曲は手動定数マップ（MANUAL_CONST）で補完します
※ 未取得の曲はOP欄に「?」が表示されます

機能一覧

  • プレイヤー情報 — アイコン・プレイヤー名・称号を右上に表示。全曲の最低ランクとOP達成率に応じてカード背景が変化
    • ■ 銀 — 全曲S以上
    • ■ 金 — 全曲SS以上 かつ OP達成率97.5%以上
    • ■ 鉑 — 全曲SSS以上 かつ OP達成率99.0%以上
    • ■ 虹 — 全曲SSS+以上 かつ OP達成率99.5%以上
  • OP集計 — 全曲のOP合計・理論値・達成率（%）をリアルタイム表示
  • ランク分布バー — MAX/SSS+/SSS/SS+/SS/S+/S の割合を色分け表示
  • コンボ分布バー — ALLPERFECT / FULL COMBO / その他の割合を表示
  • ジャンルカード — ジャンルごとのOP合計・達成率・分布をカード表示、タップでフィルター
  • ソート機能 — OP順 / ジャンル順 / レベル順 / 達成率順 の4種類
  • バッジ色分け — 行の背景色でOP達成率を視覚化（OP ÷ 理論値）
    • ■ 銀 — 90%以上
    • ■ 金 — 95%以上
    • ■ 鉑 — 98%以上
    • ■ 虹 — 99%以上
  • スコアテーブル — 曲名・種別（DX/STD）・難易度（MAS/Re:MAS）・達成率・定数・コンボ・OP・理論値・達成%を一覧表示
  • 譜面定数取得 — otoge-db / lxns.net API から自動取得、日本独自曲は手動補完

注意事項

  • maimaiNETにログイン済みの状態で実行してください
  • データ取得に数秒かかります（定数API + スコア2リクエスト）
  • maimaiNETのページ構造が変わると動作しなくなる場合があります
